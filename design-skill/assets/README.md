## 🛠️ 如何一键重新生成/换图后重跑

1. 把新的主视觉母版图 PNG/JPG 放入 `assets/` 目录（不以 `kv_` 开头）
2. 分析母版 → 抽取基础风格提示词（主体/场景/色彩/艺术/光影） → 替换本 README 中 `BASE` 字符串
3. 运行构图差异化构建脚本（或按 SKILL.MD 中的「提示词构建模板」手动拼接）
4. 在 IDE 聊天里渲染 `<img>` 预览 → 每张图右键「存储图像」 → 保存到 `assets/` 对应文件名
